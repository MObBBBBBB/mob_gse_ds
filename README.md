# 408 数据结构代码（重构 + 注释版）

本仓库仅用于 **考研 408 数据结构复习与考试书写**，不按工程项目/算法项目标准设计。

当前版本是在旧仓库代码基础上的重构版，主要工作是：

- 统一代码风格和接口为 408 考试的风格
    
- 删除不必要的工程化处理
    
- 补齐影响算法正确性的边界判断
    
- 修正部分不严谨实现
    
- 为关键代码补充注释
    

## 代码约定

- 优先参考 **408 历年真题答案、权威解析及常见教材写法**；
    
- 以适合考场书写的简洁实现为主；
    
- 数据结构代码主要采用 C 风格的 C++；
    
- 动态内存使用 `malloc/free`，空指针使用 `NULL`；
    

## 非工程化说明

只保留影响算法正确性的判断，如位序越界、非法访问、遍历结束等。

通常省略与算法无关的工程化防御，例如在前置条件已保证的情况下重复判空、处理 `malloc` 失败、异常处理、日志、RAII 等。

> 目标：让代码尽可能接近 408 主观题中的可直接书写版本，同时保留必要的算法边界和注释。


## 补充说明

1. 如果数据机构的基础操作函数如果不是重点考察，都可以直接调用，只需写注释表明是干什么的即可。

2. 默认任何的链式结构都带头节点。

3. 文件目录安排以408大纲的章节安排为准。
